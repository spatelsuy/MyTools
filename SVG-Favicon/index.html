How to use the files

  1. Download the favicon package ZIP.
  2. Extract the files into your website's public or root folder.
  3. Copy the HTML snippet from favicon-html-snippet.txt into the <head> section of your page.
  4. Keep the filenames and folder paths in the snippet in sync with where you place the files.

SVG note: An icon created with text and shapes is a true vector SVG. When you upload a PNG/JPG/WebP, the SVG contains the original image as embedded data; it does not convert the photo into vector paths.
